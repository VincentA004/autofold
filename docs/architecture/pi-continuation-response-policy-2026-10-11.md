# Pi continuation and response policy — October 11, 2026

Autofold no longer ends a scientist session merely because a provider returns a truncated response. The installed Pi SDK owns recoverable length/overflow handling, semantic compaction and continuation. Its core tool loop rejects partial tool arguments and can repair them through normal subsequent turns. Autofold retains original authority, cumulative actual/estimated cost bounds, the real deadline, ownership checks and any explicitly selected request/tool budget. No replacement retry loop, fabricated tool return or provider retry was added.

## Changes

- Removed the host `stopReason: length` termination hook. The native `AgentSession` finish/post-run lifecycle remains intact. If the SDK cannot recover, the original archive retains the incomplete response and the run reports failure honestly. Recoverable reasoning-only truncation gets the SDK's own bounded compact-and-continue behavior; truncated tool requests receive native error feedback and are never executed as partial effects.
- Removed output-token overrides from the Autofold runtime transport API, and reject untyped overrides at construction. The stream port passes Pi's own options through instead of installing an Autofold generation limit. There is no Autofold 16,384-token cap or new substitute cap. Pi/model metadata and the provider's intrinsic context/output limits still apply; response generation cannot be made literally infinite. SDK compaction-summary settings are separate from ordinary scientist generation.
- The default request timeout follows the actual runtime time allowance rather than an additional fixed five-minute cutoff. Original cumulative runtime deadlines, request cancellation, usage settlement and renewable ownership remain active. An explicitly selected request timeout is still supported.
- Terminal ordinary discovery results carry the canonical settlement receipt's `providerAccounting` separately from `modelCostUsd` estimates. The same projection is available on saved-result recovery and host-handler returns. Existing trusted parent-tree accounting is preserved rather than replaced by a supervisor-only receipt. Reported zero stays known and unknown usage is not manufactured into a zero bill.
- The scientist guidance now directs on-demand use of compact model/API references, symbol search and relevant offset/limit ranges. Full pinned source remains accessible; no new source-access restriction or hard context limit was introduced. Actual reduction of live retrieval/context overhead remains unmeasured.
